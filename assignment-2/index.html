OBJECTIVE & SCOPE

分析目的、范围与安全目标Objective, Scope and Safety Goals

本作业承接课程作业一所选对象 EH216-S，结合系统安全工程的各环节方法，对其整机系统进行深度安全分析，识别危险源与失效路径，评估风险等级，并提出设计、运行与管理层面的防护措施。

分析范围覆盖无人驾驶航空器系统的三个组成部分：航空器本体、地面控制站（远程机组）、数据链路[1]，并按子系统展开：动力系统、飞控与自动驾驶、感知导航、电池与配电、通信链路、座舱乘员、起降运行环节。

顶层不期望事件（Top-Level Hazards）：

① 飞行器失控 / 失去可控升力导致坠机；② 乘员重伤或死亡；③ 地面第三方人员、车辆或财产受损；④ 空中相撞（障碍物、其他航空器）。

严重度与概率分级（参照 ARP4761 思路）

严重度等级定义典型后果
灾难性 Catastrophic可能导致多人死亡或整机损毁坠机、乘员死亡、地面群伤
危险 Hazardous安全裕度大幅下降，乘员严重受伤多重故障叠加、长时间失联
主要 Major安全裕度明显下降，乘员轻度受伤单机单元失效后迫降、告警处置
次要 Minor轻微不适或运行受限，无实质伤害冗余切换、短时降级
无影响 No Effect不影响安全，仅维护提示非关键传感器告警

概率分级分为频繁 / 可能 / 极少 / 极微。载人航空器对灾难性失效状态要求发生概率降至“极微”量级，并通过冗余、故障检测隔离与应急程序实现风险控制。

01

方法与标准依据Methodology and Standards

本次分析遵循民用航空器系统安全评估的一般流程（ARP4754A 开发过程、ARP4761 安全评估过程）[5]，由宏观到微观、由硬件到闭环控制逐层展开：

PHA 初步危险分析

在概念 / 初期阶段识别全生命周期危险源，形成风险清单与初步分级。

FHA 功能危险评估

按系统功能识别失效条件，确定失效状态的严重度等级。

FMEA 失效模式与影响分析

自下而上分析部件失效模式、局部与高层影响、检测与补偿措施。

FTA 故障树分析

自上而下以逻辑门追溯顶层危险的底层原因组合，量化概率。

STPA 系统理论分析

从控制闭环视角识别不安全控制行为与缺失的安全约束，覆盖软件与交互。

人因与第三方分析

分析远程操作员、乘员及地面第三方相关的人因与外部风险。

02

初步危险分析 PHAPreliminary Hazard Analysis

覆盖设计、制造、地面充电、起飞、巡航、降落、故障应急、维修等全生命周期环节，识别主要危险源及初始风险等级。

危险源类别典型危险 / 触发条件初始严重度初始风险
动力电池 / 配电内短路、过充、老化、穿刺导致热失控、起火、爆炸；低温容量骤降灾难性高
动力执行单元电机 / 电调故障、桨叶断裂、接头松动；连续多个单元失效灾难性高
飞控 / 计算主飞控故障、表决逻辑失效、软件缺陷或异常重启灾难性高
感知导航GNSS 失锁 / 欺骗、视觉与雷达受雨雾强光干扰、漏检障碍危险中高
通信链路数传中断、电磁干扰、信号劫持或欺骗、链路延迟危险中高
外部环境风切变、强乱流、强降雨、雷击、鸟撞、线缆缠绕危险中
运行与人因远程操作员误判 / 误操作、违规超天气包线放行、场站外来物（FOD）主要中
乘员行为恐慌晃动、携带危险品、干扰舱内设备主要中
结构 / 材料机臂疲劳、复合材料损伤、起落架过载失效危险中

PHA 结论：电池热失控、动力群失效与飞控全失效是必须重点防控的高严重度危险源；其余危险源通过运行限制、监测告警与冗余设计降低到可接受水平。

03

功能危险评估 FHAFunctional Hazard Assessment

对核心飞行功能逐一识别失效条件及其严重度。FHA 输出的灾难性失效状态，是后续 FTA / FMEA 与冗余设计的输入。

系统功能失效条件可能后果严重度
垂直起飞 / 悬停保持无法维持悬停，快速掉高或姿态失控坠地、乘员伤亡灾难性
巡航航迹保持与避障偏离航线、未触发避障，碰撞建筑 / 线缆空中相撞、坠机灾难性
动力供给与推力分配多动力单元同时丧失，推力不足无法维持高度与姿态灾难性
电池与配电热失控起火或配电大面积丧失火灾 / 失去动力，乘员灼伤坠机灾难性
地面通信与状态监控长时间失联，远程机组失去监视与介入能力应急情况无法地面介入危险
导航定位定位失效或被欺骗，航迹错误偏航、误入限制空域或障碍区危险
应急降落决策故障后未正确判断续飞 / 迫降，错过就近着陆窗口风险扩大至灾难性危险
座舱环境与乘员约束座舱通风 / 照明 / 通信异常，乘员恐慌次生干扰，运行受限次要

FHA 原则：所有灾难性失效状态不能依赖单一硬件或单一程序消除，必须由系统冗余、故障检测与隔离、独立应急程序共同覆盖。

04

失效模式与影响分析 FMEAFailure Modes and Effects Analysis

选取关键子系统，自下而上列出失效模式、原因、局部与高层影响、检测方式与补偿措施。下表为节选（RPN 为定性排序，非定量数值）。

子系统失效模式主要原因局部 / 高层影响检测与补偿措施残余风险
动力单元单电机停转 / 单桨失效 绕组烧毁、电调故障、接头松动、桨叶损伤 该旋翼失推力；飞控重分配其余单元推力，维持姿态 转速 / 电流 / 温度实时监测；分布式冗余 + 推力重分配算法；限载重、限气象 已降低
动力单元多个相邻单元连续失效 共因故障（供电、机械结构、控制）、碰撞损伤 推力 / 力矩裕度不足，姿态难以保持 动力分组独立供电；故障隔离；Fail-Safe 就近迫降；运行包线限制 中
电池 / 配电电芯热失控 内短路、过充、机械穿刺、循环老化、低温滥用 起火 / 烟气 / 爆炸，灼伤乘员并可能致坠机 BMS 电压 / 温度 / 压差监测；热管理；电池组与乘员舱隔离；可安全移除 / 隔离；断电与返航策略[1] 高（重点防控）
飞控系统单套飞控故障 硬件失效、传感器漂移、软件异常 该通道数据被表决剔除，其余两套继续控制 三套独立飞控 + 表决机制；多传感器交叉比对；通道切换[2] 已降低
飞控系统表决 / 软件逻辑共因失效 共因设计缺陷、软件 bug、共用时钟 / 电源 三套同时输出错误指令，整机失控 异构冗余、独立电源与时钟；软件版本管控与独立安全内核；应急降级策略 中
感知导航障碍物漏检 / 误检 雨雾、强光、飞鸟、线缆等低可观测目标；传感器遮挡 避障机动未触发或误避障，航迹偏离 多传感器融合；限定航线与低高度运行；人工地面监视复核 中高
通信链路链路中断 / 受干扰 基站覆盖、电磁干扰、信号欺骗、设备故障 地面失去监视与远程介入；航空器进入自主应急 双重链路保障；独立密钥加密；断链自主续飞 / 迫降程序[2] 中高
地面站 / 调度调度指令错误或越权放行 操作员疲劳、培训不足、检查单遗漏、界面误判 在不安全条件下起飞或继续飞行 标准化检查单；天气 / 空域安全仲裁；告警分级；操作员资质管理 中
05

故障树分析 FTAFault Tree Analysis

以顶层事件“失去可控升力导致坠机”为根，自上而下用逻辑门分解。与单主旋翼直升机不同，EH216-S 多旋翼设计的核心目标就是把“动力群失效”这一组合事件的概率压到极低。

FTA 量化思路：将各底事件失效率代入布尔表达式，计算顶事件发生概率，验证是否满足适航安全目标。设计上通过分布式冗余与分组隔离，使“多个独立单元同时失效”成为 AND 组合事件，概率远低于单点失效。

06

STPA 系统理论事故分析System-Theoretic Process Analysis

STPA 不只关注零件失效，更关注控制闭环失效、不安全控制行为（UCA）与缺失的安全约束，特别适合无人驾驶 + 地面调度这类人机协同系统。系统控制回路如下：

6.1 不安全控制行为（UCA）识别

类别不安全控制行为示例可能后果
控制指令缺失故障发生后系统未触发应急迫降，缺少降级到安全状态的指令错过着陆窗口，风险扩大
控制指令错误调度系统在大风 / 低能见度告警条件下仍下发起飞许可超出飞行包线，失控风险
控制指令时序不当链路延迟导致紧急着陆指令到达过晚；或在错误航段切换控制模式应急处置失效
控制动作未被执行感知漏检障碍，飞控未执行避障机动；指令被下位机拒绝碰撞 / 偏航
反馈不充分传感器数据缺失或失真，地面站对真实状态误判错误人工介入或漏介入

6.2 应建立的安全约束

约束 1：独立安全仲裁

设置独立于调度员的天气 / 空域安全仲裁模块，不允许人工越权在不安全条件下放行。

约束 2：明确安全状态机

定义“正常 → 降级 → 就近迫降”的状态迁移规则，安全优先级高于航线与任务。

约束 3：独立安全内核

关键控制逻辑由独立安全内核承载，软件做版本管控与形式化验证，降低黑盒算法风险。

约束 4：反馈闭环完整

保证关键状态（电量、姿态、动力、链路质量）持续回传，反馈缺失时自动进入保守策略。

07

人因安全分析Human Factors Analysis

EH216-S 无机载飞行员，人因风险分为地面操作人员与舱内乘员两类。

地面远程机组 / 运维 / 充电人员

· 风险：疲劳值守、培训不足、告警误判、跳过检查单、越权操作；充电与场站维护误操作。

· 控制：标准化检查单与告警分级、操作员资质与轮班制度、健康状态监控、操作留痕与复盘。

舱内乘员（无操纵权限）

· 风险：飞行恐慌、站立或晃动、携带危险品、触碰舱内设备；语音视频沟通不畅加剧恐慌。

· 控制：舱内锁定与防护设计、起飞前安全宣教、实时语音视频联络、应急指引与约束座椅。

08

外部环境与第三方风险External Environment and Third-Party Risk

载人 eVTOL 在城市上空运行，一旦失效可能伤及地面行人、车辆与财产，属于高后果运行。外部风险包括：风切变 / 强对流、降雨与低能见度、雷击、鸟撞、建筑与线缆等障碍物、电磁环境与信号干扰，以及地面人员活动。

防护与制度短板：航线优先避开人群密集区、设置隔离 / 缓冲空域、起降场围栏隔离并制定地面应急预案；但当前载人 eVTOL 的乘员险与第三方责任险产品体系仍不完善，是商业化落地中亟待补齐的制度性安全短板。

09

安全防护措施三层体系Defense-in-Depth Safety Barriers

① 设计层（固有安全）

· 异构冗余飞控与表决；

· 分布式动力分组独立隔离；

· BMS 电池监控与热管理、乘员舱隔离；

· 故障检测 / 隔离与就近迫降逻辑；

· 加密通信与独立密钥。

② 运行层（操作安全）

· 天气 / 载重 / 电量 / 航线包线限制；

· 航线预审核与隔离空域运行；

· 场站外来物（FOD）检查；

· 实时健康监控与地面值守；

· 断链与应急程序演练。

③ 管理层（系统安全）

· 持续适航维修方案与部件寿命管理；

· 软件版本管控与安全更新；

· 操作员培训与资质管理；

· 事故 / 事件上报闭环与安全数据迭代；

· 保险与第三方责任机制配套。

10

残余风险评估与安全结论Residual Risk and Safety Conclusion

✅ 可控 / 已降低风险

单电机或单桨失效、单套飞控偏差、非关键传感器干扰等，系统具备冗余容错与降级能力，残余风险较低。

⚠️ 残余高风险

电池热失控、强风切变叠加连续感知失效、长链路中断叠加多重故障、共因软件失效等，无法完全消除，只能通过运行限制与维护管控降至可接受水平。

整体安全结论：EH216-S 通过冗余架构、自动化故障响应与地面集中管控，满足民航适航安全基线，在限定运行包线（天气、空域、载重、航线）内风险可控。但其安全不是“绝对不会出事”——一旦超包线运行，安全裕度会快速下降。无人驾驶模式下，软件逻辑、通信链路与调度闭环的安全是区别于传统有人航空器的核心重点，也是持续监管与迭代的方向。

后续安全工作建议：补充复杂气象与障碍环境下的公开试验数据；建立量化安全案例与失效率数据库；完善断链 / 共因失效的应急验证；推动第三方保险与责任制度落地。
